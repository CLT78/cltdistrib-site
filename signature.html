Où la coller

  1. Gmail sur ordinateur — Roue dentée → « Voir tous les paramètres » → onglet Général → section Signature → « Créer » → coller dans le cadre → « Enregistrer les modifications » tout en bas.
  2. Gmail sur téléphone — l'application ne gère que le texte brut. Ouvrez cette page dans le navigateur du téléphone, copiez, puis collez depuis mail.google.com en mode ordinateur ; la signature se synchronise ensuite avec l'application.
  3. Outlook — Fichier → Options → Courrier → Signatures → Nouveau → coller → OK.
  4. Thunderbird — Paramètres du compte → cocher « Utiliser HTML » → coller.

Le logo est chargé depuis votre site, il s'affiche donc chez le destinataire sans être joint au message. Certaines messageries bloquent les images par défaut : c'est pour cela que toutes les informations importantes restent en texte, jamais dans l'image.
