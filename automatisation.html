Automatiser la prospection

Envoyer, relancer et suivre les réponses, tout seul

Le site ne peut pas le faire : GitHub Pages sert des fichiers, il n'exécute aucun code. La solution est de faire tourner le code chez Google, sous votre compte — il a alors le droit d'envoyer depuis votre boîte et de lire vos réponses. C'est gratuit, sans serveur à louer et sans validation à demander à Google.

Ce que ça change concrètement

Chaque matin, tout seul
  • Les nouveaux mails partent, personnalisés selon le type d'établissement
  • Les entreprises sans réponse depuis 7 jours sont relancées, une seule fois
  • Les réponses reçues sont détectées et le statut change
  • Votre signature et votre logo sont dans chaque message
Ce qu'il faut savoir
  • Un compte Gmail gratuit plafonne autour de 100 destinataires par jour via un script — largement suffisant, mais ce n'est pas illimité
  • Le déclencheur passe à l'heure choisie, pas à la seconde près
  • Une réponse est repérée par la recherche Gmail : un accusé de réception automatique peut être pris pour une vraie réponse

La marche à suivre

Comptez un quart d'heure, une seule fois. À faire depuis un ordinateur : Apps Script ne s'ouvre pas sur téléphone.

  1. Créez un tableau

    Allez sur sheets.new. Nommez-le « Prospection CLTDistrib ».

  2. Collez la ligne de titres

    Cliquez sur la case A1, puis collez la ligne ci-dessous : les dix colonnes se remplissent d'un coup.

  3. Ouvrez l'éditeur de script

    Dans le menu du tableau : Extensions → Apps Script. Une nouvelle page s'ouvre avec un fichier presque vide.

  4. Remplacez tout par le script

    Sélectionnez le contenu existant, supprimez-le, puis collez le script fourni plus bas. Enregistrez avec l'icône disquette.

  5. Complétez vos informations

    Tout en haut du script, le bloc MOI : votre téléphone, votre zone d'intervention, votre SIRET quand vous l'aurez. Ces lignes sont vides tant que vous ne les remplissez pas.

  6. Autorisez le script

    Choisissez la fonction tourneeQuotidienne puis « Exécuter ». Google demande une autorisation : c'est normal, le script agit sur votre propre boîte.

    L'écran « Google n'a pas validé cette application » apparaît car le script vous appartient et n'est pas publié : cliquez sur Paramètres avancés, puis sur Accéder au projet.

  7. Activez l'automatisation

    Revenez au tableau et rechargez la page : un menu CLTDistrib apparaît à côté d'« Aide ». Choisissez Activer l'automatisation quotidienne.

    À partir de là, la tournée se fait chaque matin sans vous. Le menu permet aussi de tout déclencher à la main quand vous voulez.

Les colonnes du tableau

Le script lit et écrit dans cet ordre exact. La colonne Statut est le moteur : elle décide de ce qui part.

ColonneContenuQui la remplit
A EntrepriseNom de l'établissementVous
B TypeReprend exactement un des types listés dans le script — c'est lui qui choisit l'angle du mailVous
C VillePour votre repérageVous
D ContactNom de la personne, pour le « Bonjour … »Vous
E EmailSans adresse, la ligne est ignoréeVous
F StatutÀ envoyer → Envoyé → Relancé → Réponse reçueVous au départ, le script ensuite
G Date envoiRenseignée à l'envoiLe script
H Date relanceRenseignée à la relanceLe script
I Date réponseRenseignée à la détectionLe script
J NotesVos remarques, et les échecs éventuelsLes deux

Pour lancer une entreprise, il suffit donc d'écrire À envoyer en colonne F. Le lendemain matin, le mail est parti.

Le script

À coller entièrement dans l'éditeur Apps Script, à la place de ce qui s'y trouve.

Reprendre vos entreprises déjà saisies

Si vous avez commencé dans l'espace prospection, exportez-les au format tableau et collez le résultat sous la ligne de titres.

Ouvrez l'espace prospection, onglet « Mes infos », puis « Exporter pour Google Sheets ».

Quelques précautions

Allez-y doucement au début. Le script est réglé sur 15 mails maximum par tournée. Envoyer beaucoup d'un coup depuis une adresse récente est le meilleur moyen de finir en indésirables. Montez progressivement, et vérifiez vos premiers envois dans « Messages envoyés ».
La prospection entre professionnels est encadrée. Écrivez à une adresse professionnelle, sur un sujet qui concerne la fonction de la personne, et laissez toujours une porte de sortie : la mention « répondez STOP » est déjà dans la signature. Si quelqu'un demande à ne plus être contacté, retirez-le du tableau.
Relisez avant d'automatiser. Lancez d'abord « Envoyer les nouveaux mails » à la main sur une ou deux lignes, envoyez-vous un test à votre propre adresse, et vérifiez que la signature et le logo s'affichent. Ensuite seulement, activez la tournée quotidienne.
