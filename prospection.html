Importer une liste collée

Une ligne par entreprise. Chaque ligne peut contenir un numéro, le nom, l'adresse email et une note, séparés par une tabulation, un point-virgule ou deux espaces. L'ordre n'a pas d'importance : l'adresse email est reconnue toute seule.

Par où commencer

Trois minutes pour être opérationnel.

  1. La roue dentée, en haut à droite — renseignez votre téléphone et votre zone : ils figurent au bas de chaque mail.
  2. Onglet « Recherche » — décrivez ce que vous cherchez, cochez les entreprises, elles arrivent ici. Vous pouvez aussi les ajouter une par une avec le bouton +, ou coller une liste.
  3. Ici, ouvrez une fiche — « Générer le mail », vous relisez, « Ouvrir dans Gmail », vous envoyez, puis « Mail envoyé ».
  4. Sept jours plus tard — sans réponse, l'entreprise passe seule dans « Relances », avec sa relance déjà écrite.
Sauvegardez régulièrement. Vos prospects sont enregistrés dans ce navigateur, sur cet appareil. Vider les données du navigateur les efface. Utilisez « Exporter » en bas de l'onglet « Mes infos » pour en garder une copie.

Une entreprise sort de cette liste dès qu'elle a un téléphone et un e-mail. Le site internet est un plus, pas une obligation.

Signature email

À installer une fois dans Gmail : elle s'ajoutera ensuite à chaque message, y compris ceux générés ici.

Voir le code HTML
Où la coller
  1. Gmail sur ordinateur — roue dentée → « Voir tous les paramètres » → Général → Signature → « Créer » → coller → « Enregistrer les modifications » en bas.
  2. Gmail sur téléphone — l'application ne gère que le texte brut. Ouvrez mail.google.com en mode ordinateur pour coller ; la signature se synchronise ensuite.
  3. Outlook — Fichier → Options → Courrier → Signatures → Nouveau → coller.

Comment cette page fonctionne

Rien à installer, rien à connecter, aucun compte à créer.

  1. Vos entreprises — ajoutées une par une, collées depuis une liste, ou trouvées par l'onglet « Recherche ».
  2. Le mail — écrit pour le type d'établissement et la fonction du contact. Vous copiez l'objet et le message, vous envoyez depuis votre boîte, puis « J'ai envoyé ce mail ».
  3. Le suivi — au bout de sept jours sans réponse, l'entreprise passe d'elle-même dans « À relancer », avec un mail de relance déjà rédigé.
Faire partir les mails tout seuls

Un site ne peut pas envoyer de mail à votre place : il faudrait faire tourner du code dans votre compte Google. La marche à suivre existe si un jour vous en avez envie, mais ce n'est pas nécessaire pour prospecter.
